# Game Idea Checker

A single dark page that checks a Roblox game idea against four rules shared by top games: a simple name, one action a player gets right away, a bright thumbnail, and a reason players would love it.

Open `index.html` in a browser. You can double-click the file or use a `file://` address. There is no install, server, or build step.

The page scores the idea from 0 to 4 as you check each rule, warns when a name is longer than four words, and saves ideas in this browser. The first time you open it, two sample ideas are already saved.
